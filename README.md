# Space Monitor 🚀

Real-time space intelligence dashboard with live 3D solar system, ISS tracker, 
astronaut crew, satellite data & space weather — built in a single HTML file.

🔴 [Live Demo](https://nishalaashish.github.io/space-monitor-/space-monitor.html)

## Case Review Console
A practice tool for content moderation case review: policy-based decisions, written rationales, appeals and a decision log. Uses synthetic data only. Built with Claude AI.
Live demo: https://nishalaashish.github.io/space-monitor-/case-review-console.html


## Scam & Fraud Signal Checker
A rule-based demo that scans a message for common scam signals (urgency, credential requests, unusual payment methods, fake prizes, impersonation, suspicious links) and gives a 0-100 risk score with explanations. Runs in the browser, no data is sent anywhere. Built with Claude AI.
Live demo: https://nishalaashish.github.io/space-monitor-/scam-signal-checker.html
